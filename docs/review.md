# Phase-zero review

Reviewed against the workspace new-code gate before transfer into the project
repository.

## Reuse decision

No current AGX Orin/JetPack 7 Arch implementation was found in the workspace.
Public implementations located during research target older Tegra hardware,
JetPack 6, Ubuntu, or Yocto. The design reuses the supported NVIDIA
bootloader/kernel/rootfs separation and the official generic Arch Linux ARM
AArch64 rootfs rather than inventing either substrate.

## Target and assumptions

- Bash target: 5.3 locally; scripts intentionally use features available in
  Bash 4.3 and later.
- Target: inventory-confirmed Jetson AGX Orin 64 GB production module
  P3701-0005 on reference carrier P3737-0000.
- BSP: Jetson Linux 39.2.1 / JetPack 7.2.1 / kernel ABI
  6.8.12-1021-tegra, verified from the BSP `Image` and module tree.
- Root target: observed Kingston KC3000 2 TB NVMe; the user authorized erasing
  this device after confirming its contents are backed up or unneeded. eMMC is
  excluded from swap and cache.
- Arch Linux ARM is rolling; the selected rootfs and detached signature are
  pinned by digest and signing-key fingerprint in `config/inputs.lock.json`.
