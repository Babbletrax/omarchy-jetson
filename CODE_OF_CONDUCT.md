# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone who takes part in the project's spaces is
expected to follow it. Those spaces include issues, pull requests,
discussions and any other channel.

## Reporting

To report unacceptable behaviour, contact the maintainers privately. Use the
contact method on the repository owner's GitHub profile, or a private security
advisory (see [SECURITY.md](SECURITY.md)) if no other private channel is
available. All reports are reviewed and handled in confidence.

Enforcement follows the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
